**Группа:** ИНФА-231
**Вариант:** 10

### Параметры варианта
- Random state: 112
- Размер корпуса: 750
- Минимальная длина токена: 3
- Основной оператор: OR
- BM25: k1 = 1.4, b = 0.85
- Метрика: NDCG@10

### Используемые методы
- Random
- Overlap
- TF-IDF
- BM25 default
- BM25 variant 10

### Результаты

| Метод | NDCG@10 |
|---|---:|
| Random | 0.4961 |
| Overlap | 0.7144 |
| TF-IDF | 0.6789 |
| BM25 default | 0.6801 |
| BM25 variant 10 | 0.6743 |

### Вывод
Лучший результат при оценке NDCG@10 показал метод Overlap — 0.7144.
BM25 с параметрами варианта 10 получил 0.6743, не превышая значения
результата BM25 по умолчанию (0.6801).
Результаты показывают, что простое совпадение терминов может быть
эффективным на данном наборе данных.
При этом лексические методы имеют ограничения при обработке
синонимов, перефразированных выражений и языковых вариаций.
